# Privacidad y protección de datos

Este MVP se diseñó para archivos locales y dashboards agregados. Los originales se conservan; el procesamiento analítico descarta campos no autorizados y seudonimiza el identificador de cruce. No hay registros individuales en las vistas generales. Archivos, estado, parámetros de costo y modelos locales se excluyen del control de versiones.

## Ley 1581 de 2012

Esta nota orientativa no constituye asesoría jurídica ni afirma cumplimiento certificado. Antes de usar datos de empleados o candidatos, la organización debe confirmar, con su responsable de protección de datos y asesoría jurídica:

- finalidad, base legal/autoridad y autorización aplicable;
- información a titulares, derechos y canales de consulta/reclamo;
- minimización, exactitud, acceso, retención y eliminación;
- contratos y responsabilidades de encargados;
- medidas de seguridad para archivos, respaldos y estaciones de trabajo;
- revisión humana y procedimientos para corregir datos o cuestionar resultados.

La seudonimización no equivale a anonimización irreversible. La fuente original sigue conteniendo datos identificables y requiere controles de acceso, protección del equipo y política de eliminación.

## Límite de la versión actual

La aplicación local no implementa login, roles, cifrado en reposo, gestión de consentimiento, eliminación automática ni un registro auditable de accesos. No debe usarse como sistema productivo de expediente individual. La evaluación de equidad se marca como no disponible si no existen atributos de auditoría legítimos y autorizados. La ausencia de variables sensibles en el modelo no demuestra por sí sola que el sistema sea justo.
